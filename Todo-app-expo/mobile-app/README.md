# Todo mobile app

1. Copy `.env.example` to `.env` and set `EXPO_PUBLIC_API_URL` to the backend API.
2. Install and start Expo:

   ```bash
   npm install
   npm start
   ```

Use a LAN IP in the API URL when testing with Expo Go on a physical phone.

The app requires an account. Sign up or sign in before the task tabs become available; the session token is stored securely on native devices.
